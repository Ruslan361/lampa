# Lampa plugins

## Anixart (anixart.js)

Аниме с anixart.site в Lampa:

- пункт **Anixart** в меню: новинки, новые серии, онгоинги, популярные, лучшие, фильмы, анонсы, завершённые;
- фильтр как на сайте: жанр, статус, тип, год, сортировка;
- вкладка **Anixart** в поиске Lampa;
- тайтл открывается в полной карточке TMDB, просмотр — через «Смотреть» → Anixart (озвучка → сезон → серия).

Установка: Настройки → Расширения → Добавить плагин:

```
https://ruslan361.github.io/lampa/anixart.js
```

### Веб-версия и ТВ: нужен прокси

anixart.site не отдаёт CORS-заголовки, поэтому в браузере и на ТВ страницы сайта можно читать только через прокси.
По умолчанию используется публичный api.allorigins.win, но он нестабилен. Надёжнее развернуть свой —
[proxy-worker.js](proxy-worker.js) на Cloudflare Workers — и указать его адрес в Настройки → Anixart → CORS-прокси
(`https://<имя>.workers.dev/?url=`). На Android прокси не нужен.
